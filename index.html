    Installing on a phone

    1. Open this page in Chrome on the phone, open the packet with the team password and tap For this phone.
    2. Open the downloaded file. If Chrome asks, allow it to install unknown apps.
    3. A newer build installs over the old one and keeps you signed in.

    Staging is the Sales Demo hospital; Production is the live Maitra Clinic one. Use the same one on every phone you test calls with. The last five builds are kept; older phones and the emulator file are in the CI run.
